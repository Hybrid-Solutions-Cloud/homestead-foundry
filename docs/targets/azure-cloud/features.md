# Features: Azure cloud (track 1)

::: info Scope
This is the features page for the **Azure cloud** target,
track 1 of [ADR-0011](../../adr/ADR-0011-multi-target-deployment-automation).
It is a map into the canonical documents, which are the source of truth. Compare
all three targets on the [Deployment targets hub](../).
:::

The full hosted feature surface: image generation, text to speech, speech to text, frontier reasoning, agents, content safety, quotas, and an OpenAI-compatible API that any tool with a configurable base URL can point at.
