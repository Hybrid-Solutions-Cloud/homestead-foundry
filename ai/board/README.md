# board/

The live visual task board for this initiative, mirroring `ai/TASKS.md`.

- **Source:** `board.html` (version-controlled here). Open it locally in a browser, or publish it to your own hosting if you want a live view.

The board shows the 10-phase pipeline as a timeline with per-phase status and the owning agent. It is refreshed as phases complete. `ai/TASKS.md` remains the source of truth.

The maintainer's own published copy of this board is a private link and is deliberately not referenced here.
